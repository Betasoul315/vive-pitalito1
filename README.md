# Vive Pitalito — Fase 2 — Versión final de contenido

Aplicación multimedia bilingüe (ES/EN) desarrollada con HTML5, CSS3 y JavaScript.

## Contenido
- 4 categorías y 8 subcategorías.
- 24 experiencias basadas en la Base Maestra de investigación.
- 18 experiencias con información verificada en la base maestra.
- 6 experiencias marcadas como pendientes de verificación.
- Enlaces internos entre categorías y experiencias.
- Enlaces de Google Maps para las 24 experiencias.
- Fuentes enlazadas cuando la base maestra aporta URL.
- Mapa Leaflet/OpenStreetMap.
- Selector ES/EN.

## Importante
Las fotografías generales de referencia no deben interpretarse como fotografías documentales de cada experiencia. La base maestra separa explícitamente contenido verificado de contenido pendiente.
